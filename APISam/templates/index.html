Date and Volume of Highest Visitation to Federal Agency Websites in 2026

Welcome to this API providing the date and volume of the highest website visitation to federal agencies.

This API provides the date(s) and highest number of website visitors to an Agency's hostname in 2026. Data Source: https://open.gsa.gov/


Pick an endpoint to retrieve data on a specific Agency using the query string root/endpoint. Use root/endpoint/2026?limit={int} to pull back a sample number of records from the current year.
